# 🎬 Toon4u Backend - Anime API

Yeh **Toon4u** website ka asli backend engine hai. Yeh API anime ka data, posters, aur streaming links fetch karne ke liye banayi gayi hai.

## 🚀 Features
* **Trending Anime:** Latest trending posters load karta hai.
* **Search Function:** Kisi bhi anime ko search karne ki salahiyat.
* **Fast & Reliable:** Amvstr API ka istemal karta hai jo "Down" nahi hoti.
* **Vercel Deployed:** Direct cloud par chalta hai.

## 🛠️ Tech Stack
* **Node.js** (Runtime)
* **Express.js** (Server Framework)
* **Axios** (Data Fetching)
* **Vercel** (Hosting)

## 📁 Files Structure
* `index.js`: Main coding aur logic file.
* `package.json`: Dependencies aur scripts.
* `vercel.json`: Vercel deployment settings.

## 📝 How to use?
Aap is API ko apni HTML/JavaScript website mein base URL ke taur par use kar sakte hain:
`https://your-vercel-link.vercel.app/anime/trending`
